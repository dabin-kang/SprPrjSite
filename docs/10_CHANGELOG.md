# 10. CHANGELOG

## 매거진·프로젝트 본문 이미지와 줄 간격

### 추가

- 공용 본문 에디터에서 이미지 업로드 및 본문 내 삽입, 줄 간격 조절 지원
- 프로젝트 섹션과 매거진 본문에 같은 서식 편집기 연결
- 업로드 이미지는 기존 관리자 업로드 API와 Supabase Storage를 사용
- 공개 상세 페이지에서 허용된 태그·이미지 주소·서식만 렌더링

### 검증

- 프런트엔드 production build 성공
- 본문 sanitizer 테스트 3건 통과
- 모의 업로드/API 흐름에서 매거진·프로젝트 본문 이미지와 줄 간격의 저장·표시 확인
- 실제 Supabase 업로드와 운영 배포는 검증하지 않음

## 매거진 본문 서식 편집기

### 추가

- 매거진 본문에 선택 영역 굵기·글자 크기·자간 조절 도구 추가
- 서식 본문을 상세 페이지에서 유지하며 안전한 태그와 서식만 렌더링

### 검증

- 프런트엔드 production build 성공
- 매거진 본문 sanitizer 테스트 2건 통과

## 매거진 상세 이동 및 관리자 화면 개선

### 추가

- 매거진 생성 API가 생성된 매거진 ID를 반환하고 관리자 등록 직후 해당 상세 페이지로 이동
- 매거진 상세 전용 라우트 및 화면 추가, 공개 글은 일반 조회 API로 비공개 글은 관리자 조회 API로 표시
- 관리자 매거진 목록에서 상세 페이지로 이동하는 링크 추가
- API 기본 주소 끝의 슬래시를 정규화해 설정 값에 따른 이중 슬래시 요청 방지

### 변경

- 공개 매거진 카드가 모달 대신 매거진 상세 페이지로 이동
- 관리자 화면의 사이드바·페이지 헤더·콘텐츠 패널·테이블 스타일을 정리하고 모바일 메뉴 레이아웃 개선

### 검증

- 프런트엔드 production build 성공
- 백엔드 Gradle 테스트 성공
- 운영 API 연동 및 Railway/Vercel 배포는 수행하지 않음

## 관리자 CMS 전체 기능 구현

### 추가

- 대시보드 실시간 집계와 회원·이벤트·프로젝트·문의·매거진 관리 탭
- 프로젝트 상세 섹션 및 이미지 관리 UI와 관리자 API
- 프로젝트 섹션 재저장 시 기존 DB 이미지 참조를 먼저 제거해 고아 레코드 방지
- DB 프로젝트의 공개 상세 페이지 렌더링
- 이벤트 수정 시 이미지와 날짜 필드를 명시적으로 비우는 요청 필드
- 이벤트 필드 보존/비우기 동작을 확인하는 서비스 단위 테스트
- 공개 헤더의 매거진 메뉴와 API 기반 매거진 목록/상세 화면

### 변경

- 관리자 콘텐츠 목록에서 샘플 데이터 fallback 대신 API 오류와 빈 상태를 표시
- 프로젝트 공개 목록/상세는 공개 상태인 데이터만 반환하도록 관리 경로 분리
- 매거진 공개 조회와 관리자 전체 조회 경로 분리
- 프로젝트 상태를 임시저장, 공개, 비공개로 관리
- 프로젝트 개요 문서에 현재 소스 구현과 미검증 운영 항목 반영
- 매거진 임시 샘플 fallback을 제거하고 API 오류·빈 상태·재시도 표시
- 프로젝트 이미지 MyBatis 조회/저장과 CMS 기준 migration을 실제 DB의 `storage_path` 컬럼에 맞춤

### 검증 한계

- Frontend production build 성공
- Backend Gradle test 성공
- 실제 MySQL, Supabase, Vercel, Railway 연결과 배포 상태는 검증하지 않음
- 수정 backend는 아직 운영에 배포되지 않아 프로젝트 상세/수정 API 재검증 필요
- CMS migration SQL은 실행하지 않음
