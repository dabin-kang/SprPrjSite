# 10. CHANGELOG

## 관리자 CMS 전체 기능 구현

### 추가

- 대시보드 실시간 집계와 회원·이벤트·프로젝트·문의·매거진 관리 탭
- 프로젝트 상세 섹션 및 이미지 관리 UI와 관리자 API
- 프로젝트 섹션 재저장 시 기존 DB 이미지 참조를 먼저 제거해 고아 레코드 방지
- DB 프로젝트의 공개 상세 페이지 렌더링
- 이벤트 수정 시 이미지와 날짜 필드를 명시적으로 비우는 요청 필드
- 이벤트 필드 보존/비우기 동작을 확인하는 서비스 단위 테스트
- 누락된 경우 프로젝트 섹션/이미지 테이블만 생성하는 별도 idempotent migration
- 공개 헤더의 매거진 메뉴와 API 기반 매거진 목록/상세 화면

### 변경

- 관리자 콘텐츠 목록에서 샘플 데이터 fallback 대신 API 오류와 빈 상태를 표시
- 프로젝트 공개 목록/상세는 공개 상태인 데이터만 반환하도록 관리 경로 분리
- 매거진 공개 조회와 관리자 전체 조회 경로 분리
- 프로젝트 상태를 임시저장, 공개, 비공개로 관리
- 프로젝트 개요 문서에 현재 소스 구현과 미검증 운영 항목 반영
- 매거진 임시 샘플 fallback을 제거하고 API 오류·빈 상태·재시도 표시

### 검증 한계

- Frontend production build 성공
- Backend Gradle test 성공
- 실제 MySQL, Supabase, Vercel, Railway 연결과 배포 상태는 검증하지 않음
- 운영 API에서 프로젝트 목록은 응답하지만 공개 상세는 500을 반환함; migration 적용 여부는 미확인
- CMS migration SQL은 실행하지 않음
