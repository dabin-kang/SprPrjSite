# AGENTS.md

## 1. 프로젝트 기본 원칙
- 기존 프로젝트 구조를 먼저 분석한다.
- 기존 기능을 임의로 삭제하지 않는다.
- 기존 데이터베이스 구조를 먼저 확인한다.
- 프론트엔드와 백엔드의 연결 관계를 확인한다.

## 2. 코드 수정 원칙
- 수정 전에 관련 파일을 먼저 읽는다.
- 불필요한 파일 생성 및 중복 코드를 방지한다.
- 기존 코드와 호환되도록 구현한다.
- 환경변수와 인증정보를 코드에 직접 입력하지 않는다.

## 3. 개발 진행 원칙
- 작업 전 구현 계획을 설명한다.
- 작업을 작은 단계로 나누어 진행한다.
- 각 단계가 끝나면 테스트한다.
- 오류가 발생하면 원인을 먼저 분석한다.
- 완료된 작업은 docs/09_TODO.md에 반영한다.
- 주요 변경 사항은 docs/10_CHANGELOG.md에 기록한다.

## 4. Git 관리
- 사용자 승인 없이 커밋하거나 푸시하지 않는다.
- 기존 변경 사항을 임의로 덮어쓰지 않는다.
- 배포 전 빌드 및 테스트 결과를 확인한다.

## 5. 작업 보고
- 수정한 파일
- 수정한 내용
- 실행한 테스트
- 테스트 결과
- 남은 문제점

위 항목을 작업 완료 시 보고한다.
